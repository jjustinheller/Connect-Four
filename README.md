Connect Four

The problem that I am trying to solve is determining who is better at Connect 4 between my friend and I.  We are both always arguing about who's better, but the argument never gets settled because we both only talk about the games we won. I want to find a way to determine who is actually better. 

I am going to build a 2-player Connect 4 game in Java that is able to run in the terminal. It will save the results of all games played to a text file, showing win, loss, and tie records to determine who is actually better. 

Language: Java 
Libraries, packages, or external tools: Scanner, Printwriter, String,format, and Random
Data Storing: Text file

MVP
Print the 6 by 7 board in the terminal
Switch turns between the 2 players and drop the pieces in
Determine if there is a winner or a draw
Make sure each move is valid
Show the history of wins, losses, and ties

Connect Four V2.0+
Print stats about win record such as win streak and win percentage
Have a play again option
Be able to play against a computer for practice
Be able to undo your last move
